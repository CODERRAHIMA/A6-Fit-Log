# Fit Log 🏋️

**Your simple strength-training planner.** <br/>
Browse exercises, check instructions and training stats, then add up to five lifts to today's plan. Save other workouts for later; your plans stay in your browser.


## ✨ Key Features

1. **🏋️ Explore the workout library** — Browse a curated collection of strength exercises, with muscle groups, required equipment, difficulty, duration, and other stats at a glance.
2. **📋 Get exercise details** — Open a workout for its description, step-by-step instructions, sets and reps, estimated calories, duration, and rating.
3. **📅 Build today's plan** — Add exercises to a focused daily workout list, with space for up to five lifts.
4. **🔖 Save workouts for later** — Keep a separate saved list so exercises you may want to try remain easy to find.
5. **↕️ Organize your plan** — Switch between today's plan and saved workouts, then sort either list by duration, calories, or rating.

## 🧰 Built With

### 💻 Frontend
- **Next.js 16** — App Router and server-rendered pages
- **React 19** — Interactive application UI
- **JavaScript (ES6+)** — Modern JavaScript features and application logic
- **Tailwind CSS 4** and **daisyUI 5** — Styling and UI utilities

### 📚 Libraries
- **Lucide React** — Interface icons
- **React Toastify** — Toast notifications

## 🚀 Run Locally

**Prerequisites:** Node.js and npm.

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```
